# Data

The raw XLSX files in `raw/` are local source files for this project. They contain tweet IDs, tweet text, language proportions, retrieval status, and social-media metadata.

They are intentionally excluded from Git by the root `.gitignore`. Before sharing any data publicly, confirm that publication is permitted and remove or anonymize usernames, author IDs, tweet text, and other metadata as required.

The aggregate results in `../results/dataset_summary.csv` do not contain tweet-level content.
